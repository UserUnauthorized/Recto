# 课程讲解文档

让基础不牢、没有完整听课的学生读得懂、能跟着做题。文档应可独立阅读，不需要边看 PPT 边补全推理；压缩重复内容，保留理解所需的条件和步骤。

## 输入、权限与交付

- 需要可读取的课程材料和本次章节范围；先从附件、目录和会话确定，已有答案不重新询问。用户只给主题时可写通用讲解，但不能声称覆盖了未读的课件。
- “根据课件制作讲解／补课文档”授权在指定范围内重组解释、合并重复内容和精选或改编例题。明确要求保持原顺序、保留全部题目、只改一节时，按该限制处理；“排版一下／原样转换”交给 `$recto` 的转换模式，不执行本流程。
- 默认面向需要补基础的课程学习者；用户已说明水平时沿用。不要因为受众基础弱就写成长篇科普，也不要把讲解压成只有结论的提纲。
- 默认交付 `.typ`、`.pdf` 和可重编译的源文件包；用户指定其他交付范围时遵从。要求 Word 时再增加 `.docx`。
- **排版依赖：`$recto` skill。** 本插件包含该依赖；单独安装本 skill 时也须准备 Recto。通过当前环境的技能列表定位并读取其 `SKILL.md`，不硬编码安装路径，不复制它的模板、字体或导出脚本。系统工具和字体按 Recto 的依赖检查准备。

## 1. 确定讲解语言

分别识别三个信息：**主要输出语言、材料语言、已明确的考试／工作语言**。它们可能不同，也可能一致。

1. 主要输出语言先遵从本次明确要求，其次沿用会话已确定的偏好，再依据用户自己交流时主要使用的语言。不要把附件、引用内容或 skill 本身的语言当作用户偏好。确实无法判断且影响成文时才问一句。
2. 检查材料实际语言；混合语言时按概念保留对应的原文词。考试语言只有用户或材料明确说明时才采用，不能从外语 PPT 推断“考试也用外语”。
3. 标题、正文、推导解释、图注和答案以主要输出语言为主。若材料语言不同，在关键概念首次出现时写成“主要语言术语（材料原词）”；优先保留读课件、识别题干、区分易混概念需要的名称、缩写和指令词，不逐句双语复述，也不为日常词汇逐一加注。
4. 已明确的考试语言不同于主要语言时，补充必要的考试术语或题干表达。若它又与材料语言不同，只对确有需要的词增加对应项，避免每个概念都堆三种语言。选用外语自测题时，用主要语言解释题意和答案；没有此需求时不强加外语试卷。
5. 原词优先核对课件、教材或题解，全文统一同一概念的译法和缩写。歧义影响理解时查证或说明，不能凭词形猜译。两种语言相同时，不强制增加第三种语言；用户明确不要双语标注时遵从。

例如，主要语言为西班牙语、材料为英语时可写 `campo eléctrico (electric field)`；主要语言为英语、材料为中文时可写 `electric field（电场）`。示例只说明标注关系，不设定默认语言。公式符号及其约定沿用材料，不因翻译悄悄更名。

## 2. 读材料，建立知识主线

先读目标章节和相关题解；已有 OCR 可帮助检索，但公式、图中标记、表格和可疑识别必须回看原页。只读目录或 OCR 不能证明已覆盖全章。

在工作文件中简记“原页／知识点 → 讲解位置／合并或省略理由”。按概念分组即可，不要求逐页复述。区分：核心定义与方法、理解所需前置知识、重复例题、材料明确标注的选读部分。不能仅凭“看起来不常考”删知识点；用户要求全覆盖时，保留所有不同概念和已要求的题目，压缩重复叙述。

按学习依赖安排顺序：这节解决什么问题，先需要理解什么，公式或方法为何成立，怎样判断何时使用。可以重排 PPT；不要把“课件第几页讲了什么”当作正文主线。对选读内容可简要交代用途或放入末尾，不自行预测考试范围。

## 3. 写得简洁，也讲清楚

围绕每个关键概念解释含义、条件、方法选择和一个必要的应用；只写这一节确实需要的部分，不把它们机械套成四个固定栏目。

- 先解释符号、坐标约定、单位和前提，再使用公式。关键公式给最短的可跟随推导或直观解释；“显然”“代入可得”不能掩盖学生最容易卡住的那一步。
- 按不同解题方法和易错点选代表题；同一套路合并，不凑题数。解答说明为何选这个方法、关键中间步骤和结果检查。改编题标明“改编自”及原题位置，新增题标明“示例／自测”，不能伪装成老师原题；这些标签也用主要语言。
- 需要复习练习时加少量可检验理解的自测与简洁答案；不固定数量，不把自测、术语表或总结表强加给每篇文档。若术语较多且散落全文，可用短表辅助查找。
- 核对公式条件、符号、量纲、正负号和例题结果；复杂数值或变换可用小段计算交叉检查。来源有误时先独立验证，确认后在讲解中用正确结果并简注原页及更正；不确定的冲突保留疑点，不假装已解决。
- 删去空泛开场、鼓励口号、同义复述、机械过渡和过密小标题。段落之间按因果、条件、比较或推导衔接；不为“去 AI 腔”牺牲严谨性，也不需要用户另外安装写作技能才能完成。

篇幅由知识量和用户要求决定，不固定为某次样张的页数。页数过多时先删重复、合并例题；不能靠缩小字号、去掉必要条件或跳过关键推导来压页。

## 4. 选择插图与成熟版式

默认沿用 Recto 的 `reference` 讲义样式；用户已有样式选择时遵从。以清楚的标题层级、统一字体、适当留白、易读公式与图注形成完成度，不增加装饰封面、卡片墙或每节一张图。

优先利用课件和题解中能解释几何、结构或过程的图。截取有效区域，保留坐标、单位、图例、方向箭头和必要上下文；不要整页截图充当讲解，也不要裁掉影响判断的标记。图注用主要语言说明读者应看出什么并注明来源页；图内外语标签在理解所需处给出对应解释，不伪装成已翻译的原图。

原图不清晰或不适合成品尺寸时，选择更清楚的来源或基于已核实关系重绘，并标明改绘。新增图只用于解释正文难以呈现的关系；严谨示意图、函数曲线和数据图保留图源或数据，不用装饰图片代替科学关系。缩放后再看标签是否可读，颜色不能成为唯一区分方式。

## 5. 导出并逐页验收

保存一份语义化 Markdown 正文及本地图片，再把**已完成的讲解稿**交给 Recto 的转换流程：仅排版，不再次改写、扩写或配图。读取它当前的输入语法、依赖与导出说明后，从公开导出入口生成所需格式；不要另造导出器。

导出前确认模板的语言设置与主要语言一致；仅改变正文或源稿中的语言标签，不代表模板会自动使用它。按本次实际语言检查字体字形、标点、断行及书写方向。Recto 的现有字体和模板不能保证覆盖所有语言；发现缺字或方向错误时先解决对应字体／排版支持并重验，不以“文件编译成功”代替可读性，也不把语言选择规则说成所有文字系统都已实测。

导出后依次核对：

1. 知识主线、核心内容覆盖和取舍符合本次授权；原文术语对应正确，主要语言贯穿全文。
2. 公式、单位、条件和例题计算正确，图中符号与正文一致；数学元素数量相同只用于发现漏项，不能证明符号正确。
3. PDF 逐页渲染查看正文密度、公式溢出、表格、图注、缺字、孤立标题和分页。需要修改时回到共同源重新导出，再检查受影响页面。
4. 源文件包包含正文、所需图片、可分发字体及许可证、重编译说明；在解包目录重新编译验证资源完整。不要打包原始课件、私人题解或内部 QA 文件来代替必要资源。

## 缺口与交付说明

指定材料未提供／无法读取、范围无法辨明，或关键公式和原文术语的歧义无法解决时，说明具体缺项并索取必要信息；可先完成不受影响部分，不编造缺失内容。Recto 不可用时先保留讲解稿，明确缺少排版依赖并请求可用路径或安装条件，不能声称已交付 PDF。环境安装遵从用户已有授权。

最终给成品和源文件包链接，简述内容取舍及真正未解决的限制。区分指令走读、导出成功、内容核对、逐页视觉检查和解包重编译，不把其中一种说成另一种已经完成。
