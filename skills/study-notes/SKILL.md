# 讲义、复习与题目讲解

先判断读者这次要学会什么，再选择写作流程。首次学习需要建立概念，复习需要恢复联系，指定题目需要完整解释解法；三者的篇幅和组织不能互相代替。

## 1. 确定范围与流程

从本次请求、附件和已有会话确定范围、学习基础、语言、输出格式与已知难点。已有答案直接沿用，只询问会改变结果且无法从材料确定的缺项。

| 请求 | 读取与动作 |
|---|---|
| 原样转换、排版或逐句翻译 | 原样转换与排版交给 `$recto` 转换流程；逐句翻译按翻译请求处理，不启用教学重组 |
| 讲指定作业、题号、截图中勾选的题 | 读取 [指定题目讲解](references/problems.md)，以题目和小问为覆盖单位 |
| 没学过、第一次学、只看这份讲义、不再看课件 | 读取 [首次学习](references/learning.md)，以完整的学习依赖为主线；即使标题叫“复习”，也按实际基础处理 |
| 已学过，要求串讲、考前复习、补漏或公式速查 | 读取 [复习与速查](references/review.md)，以知识联系、方法判断和已知薄弱点为主线 |
| 只说“做讲义”，未说明基础 | 读取 [首次学习](references/learning.md)，默认写可独立阅读的学习讲义；确实影响范围的缺项才询问 |

同一请求包含讲义和作业时，分别应用对应流程。只改一节就只处理该节；“简洁”决定删重复，不授予删知识点或指定题目的权限。篇幅按内容需要决定，不继承样张页数、例题数或插图数，也不用缩小字号来压页。

主要输出语言、材料语言或已明确的考试语言不同时，读取 [语言规则](references/language.md)。本次明确要求优先；否则沿用用户主要交流语言。公式符号沿用材料约定，附件或引用的语言不等于用户偏好。

## 2. 读取并核对材料

以本次指定或会话明确关联的材料为来源；同目录文件不自动纳入，避免把其他任务的答案当成本题依据。先读指定章节、作业清单及相关题解。OCR 用于检索；公式、图中标记、表格和可疑识别必须回看原页，只读目录不能声称已覆盖全章。只给主题时可写通用讲解，但不能声称覆盖了未读的课件。

在交付目录以外简记“原页／知识点或指定小问 → 讲解位置／合并或省略理由”。全覆盖请求保留所有不同概念及指定题目；明确选读内容可简述或置于末尾，不能凭猜测考试范围删掉。逐题讲解的选题和原文约束以对应参考文件为准，不应用精选例题规则。

材料缺页、题号无法确定或关键符号不清时，指出具体缺项，先完成不受影响部分；不通过补造题干或假定参数完成覆盖。

## 3. 写作、计算与配图

- 在解释型正文中，新概念和符号首次用于推理前解释其含义、条件和约定。解答写出方法选择、关键中间步骤和结果检查；“显然”“代入可得”不能跨过读者所缺的一步。
- 独立推导和计算，再与课件或已有答案比对。核对定理前提、定义域、量纲、符号、向量方向与结果；复杂变换可用计算工具交叉检查。发现冲突重新验算，未解冲突明确保留疑点。
- 生成的讲解采用已核实的正确结果并注明原页勘误；原题引文仍忠实保留，不能把更正悄悄写回原题。几何题检查给定点是否满足条件，极值题区分局部、绝对、鞍点与判别失效；电路题核对连接、极性和开关前后状态。
- 按概念或推理组织段落，删去口号、空泛开场、同义复述与过密小标题。精简文字不精简必要条件；不把概念、条件、步骤机械拆成每节相同的栏目。
- 优先采用材料中能解释几何、结构或过程的图，保留坐标、单位、图例、箭头与必要上下文，图注说明用途和来源页。清晰原图可裁取；重绘先核实关系并标明改绘。电路连接点、交叉线、开关位置与参考方向必须与题干一致。
- 函数图和科学示意图基于核实的函数、坐标或结构生成，保存所需图源或数据；不以整页截图代替讲解。缩放后核对标签可读性，灰度下仍能区分关系。没有解释作用就不加图。

## 4. 交给 Recto 排版

**依赖：`$recto` skill。** 插件包含该依赖；单独安装时也须准备 Recto。通过当前环境技能列表定位并读取其 `SKILL.md`，按其依赖检查准备系统工具与字体，不硬编码安装路径，也不复制导出器、模板或字库。找不到 Recto 时保留讲解稿，说明排版缺项；安装遵从已有授权。

默认交付 **Markdown、LaTeX 和 PDF**，需要 Word 时增加 `.docx`，用户明确增减格式时遵从。采用 Recto 的 `reference` 样式：A4、白底黑字／灰度、清晰标题层级和页码；已有风格选择优先。无需装饰封面、色块或卡片。目录沿用 Recto 的单份 Markdown、共享 `media/` 和 `latex/` 约定，不默认另加 ZIP、说明文件或 QA 产物。

正文写成语义化 Markdown，公式使用可转换的 LaTeX 数学语法，由 LuaLaTeX 排版，不以 Unicode 字符拼凑或截图代替公式。不支持任意 raw TeX 混入；宏超出当前数学包支持集时停止并指出，不自动安装或改写公式。

完成稿交给 Recto 时采用**转换模式**，只排版，不再次重组、扩写或配图。读取它当前的输入语法与导出说明，从公开入口生成文件。导出前核对模板语言、字体字形、标点、断行与书写方向；正文语言标签不保证模板支持该文字系统。

## 5. 验收与交付

按所选流程的完成条件验收内容，再检查成品：

1. 对照覆盖记录，确认知识点、指定题目与小问、原文术语、讲解语言都符合范围。正文能独立阅读，所需图形和条件没有留在课件里。
2. 逐项核对公式、推导、计算、单位与图文符号。公式数量只能帮助查漏，不能证明符号正确；结构完整也不能证明学生读得懂。
3. PDF 逐页渲染查看缺字、公式溢出、表格、图注、标题孤行与分页；同级小问起始位置一致，多行推导对齐。避免题干末尾与解答开头无故分离；长题允许在逻辑边界分页，避免整题强制同页造成大空白。修改共同源后重导出并复查受影响页面。
4. 检查实际文件能打开、链接指向本轮成品。保留 LaTeX 时从最终目录重新编译，核对 Markdown 和 LaTeX 的图片引用；仅保留实际选用的开源字体与许可证。交付目录清理与资源去重按 Recto 约定执行，只清理能确认的本轮生成文件，原始材料和来源不明文件保留。

最终给出实际成品链接，简述范围、PDF 页数、适用时的题目与小问数量，以及未解疑点。下载失效时重新检查文件并提供有效链接，不能只复述旧链接。区分指令走读、内容核对、导出成功、逐页视觉检查和最终目录重编译；未完成的层次如实说明。
