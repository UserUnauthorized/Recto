# 讲义、复习与题目讲解

先判断读者这次要学会什么，再选择写作流程。首次学习需要建立概念，复习需要恢复联系，指定题目需要完整解释解法；三者的篇幅和组织不能互相代替。

读取本 skill 的参考文件时，沿用宿主提供的目录或云端技能资源入口。云端使用同一 authority、包和资源标识读取；若提供 `skills.list` / `skills.read`，以 `{"authority":{"kind":"cloud"}}` 定位当前包并读取其 `main_resource`，参数以当前工具说明为准。相对引用留在本 skill 内，`skill://` 等标识不当作文件路径或网页地址。资源不可读时报告具体缺项，不搜索 GitHub 或公开网页补取插件实现。

## 1. 确定范围与流程

从本次请求、附件和已有会话确定范围、学习基础、语言、输出格式与已知难点。已有答案直接沿用，只询问会改变结果且无法从材料确定的缺项。首次写文件前，按 [Recto 交接](#4-交给-recto-排版) 确定输出路径与下载名。需要 PDF 时此时就确认 Recto 的运行目录并执行对应格式的 doctor。若云端字体只能列名，先走 Recto 的同包恢复流程；仍不可用时，本轮继续写稿并走其 PDF 降级分支。

| 请求 | 读取与动作 |
|---|---|
| 原样转换、排版或逐句翻译 | 原样转换与排版交给 `$recto` 转换流程；逐句翻译按翻译请求处理，不启用教学重组 |
| 讲指定作业、题号、截图中勾选的题，或给作业附件只说“制作讲解” | 读取 [指定题目讲解](references/problems.md)，先确定作答范围、答案语言与必需分区，再逐小问覆盖 |
| 没学过、只靠讲义学，或要自学讲义／普通讲义但未说明基础 | 读取 [首次学习](references/learning.md)，先写出初学者能读通的第一段，再续写推导。标题叫“复习”但明确没学过，也走这个流程 |
| 已学过，要求串讲、考前复习、补漏或公式速查 | 读取 [复习与速查](references/review.md)，以知识联系、方法判断和已知薄弱点为主线 |

同一请求包含讲义和作业时，分别应用对应流程。只改一节就只处理该节；“简洁”决定删重复，不授予删知识点或指定题目的权限。篇幅按内容需要决定，不继承样张页数、例题数或插图数，也不用缩小字号来压页。

主要输出语言、材料语言或已明确的考试语言不同时，读取 [语言规则](references/language.md)。本次明确要求优先；否则沿用用户主要交流语言。公式符号沿用材料约定，附件或引用的语言不等于用户偏好。

## 2. 读取并核对材料

以本次指定或会话明确关联的材料为来源；同目录文件不自动纳入，避免把其他任务的答案当成本题依据。先读指定章节、作业清单及相关题解。OCR 用于检索；公式、图中标记、表格和可疑识别必须回看原页，只读目录不能声称已覆盖全章。只给主题时可写通用讲解，但不能声称覆盖了未读的课件。

在交付目录以外简记“原页／知识点或指定小问 → 讲解位置／合并或省略理由”。全覆盖请求保留所有不同概念及指定题目；明确选读内容可简述或置于末尾，不能凭猜测考试范围删掉。逐题讲解的选题和原文约束以对应参考文件为准，不应用精选例题规则。

材料缺页、题号无法确定或关键符号不清时，指出具体缺项，先完成不受影响部分；不通过补造题干或假定参数完成覆盖。

## 3. 写作、计算与配图

- 默认写成可独立使用的讲义。每道选入的例题和练习先给完整题干：要做什么、已知条件、所需数据和题图，再按请求给提示或解答。把推理要用的定义、公式条件或表格数据放在首次用到的地方。题号、页码和链接可随文标注，供读者回查。只有用户明确要对照课件阅读、只列索引等形式时，才把指定内容留在原材料里。
- 讲解从读者已经会的地方接起。基础不明时，把要教的知识当作新内容。先用日常话讲清眼前的问题，再给正式名称。首次用符号推理前，说清它在例子里指什么、按什么约定使用。如果一句解释还要靠另一个生词才能懂，就换成读者能观察、比较或算出来的例子。解题时交代选方法的依据、成立条件、关键步骤和结果检查。
- 独立推导和计算，再与课件或已有答案比对。核对定理前提、定义域、量纲、符号、向量方向与结果；复杂变换可用计算工具交叉检查。发现冲突重新验算，未解冲突明确保留疑点。
- 生成的讲解采用已核实的正确结果并注明原页勘误；原题引文仍忠实保留，不能把更正悄悄写回原题。几何题检查给定点是否满足条件，极值题区分局部、绝对、鞍点与判别失效；电路题核对连接、极性和开关前后状态。
- 按概念或推理组织段落，删去口号、空泛开场、同义复述与过密小标题。精简文字不精简必要条件；不把概念、条件、步骤机械拆成每节相同的栏目。
- 题图随题干嵌入。解法用到空间边界、电路连接或过程变化时，在第一次读这个关系的步骤旁放图，正文带读者用图做一次判断。课件把图放在下一页时也取回随题使用。优先裁取清晰原图，保留坐标、单位、图例和箭头；缺图或原图难读时，依据已核实的条件绘制示意图。图注交代读法，原图或改绘标明来源页，自绘标明依据。
- 函数图和科学示意图基于核实的函数、坐标或结构生成，保存所需图源或数据；不以整页截图代替讲解。缩放后核对标签可读性，灰度下仍能区分关系。没有解释作用就不加图。

排版或直接交付文字前，按所选流程的完成条件校订正文。首次学习稿写完后，[从第一段重读并修改跳步](references/learning.md#首次阅读校订)。

## 4. 交给 Recto 排版

**依赖：`$recto` skill。** 插件包含该依赖；单独安装时也须准备 Recto。通过当前环境技能目录或资源工具定位并读取它的入口；插件调用优先选同一插件内的 Recto，随后按它的资源准备和依赖检查流程取得执行目录、系统工具与字体。云端随包文件的原样落盘由 Recto 负责，本 skill 不另建或改写导出器、模板或字库。完全找不到 Recto 时，说明缺项。普通阅读 PDF 可将已核对的讲解排成独立 XeLaTeX 稿，用本机中文字体编译；无引擎就交付含正文、配图和编译命令的源码。若用户只接受正式版，则交共同源和配图，标明正式排版待完成。

默认交付 **Markdown、LaTeX 和 PDF**，需要 Word 时增加 `.docx`，用户明确增减格式时遵从。采用 Recto 的 `reference` 样式：A4、白底黑字／灰度、清晰标题层级和页码；已有风格选择优先。无需装饰封面、色块或卡片。写文件前按 Recto 的“输出路径与下载名”分支确定位置和名称；交接沿用已确定的文档名，目录资源和下载副本均由它的规则处理。不默认另加 ZIP、说明文件或 QA 产物。

正文写成语义化 Markdown，公式使用可转换的 LaTeX 数学语法，由 LuaLaTeX 排版，不以 Unicode 字符拼凑或截图代替公式。不支持任意 raw TeX 混入；宏超出当前数学包支持集时停止并指出，不自动安装或改写公式。

完成稿交给 Recto 时采用**转换模式**，只排版，不再次重组、扩写或配图。读取它当前的输入语法与导出说明，从当前安装的 Recto 公开入口生成文件，保存本轮导出报告并用同一入口完成 `--verify-report` 复验；环境资源或编译工具不可用时，按 Recto 的“正式 PDF 受阻时的交付”选择兼容 PDF 或本机编译工程。兼容版注明引擎；正式验证只用于正式输出。导出前核对模板语言、字体字形、标点、断行与书写方向；正文语言标签不保证模板支持该文字系统。

## 5. 验收与交付

1. 对照覆盖记录核对知识点、小问、术语和语言。对独立使用的成稿合上原材料，逐题遮住解答：能否仅凭讲义说出要求、找到每个已知量、看清所指图表？再顺读解答，遇到必须翻原页才能理解的一步，就把缺的内容补在该处再读。
2. 逐项核对公式、推导、计算、单位与图文符号。公式数量只能帮助查漏，不能证明符号正确；结构完整也不能证明学生读得懂。
3. PDF 逐页渲染查看缺字、公式溢出、表格、图注、标题孤行与分页；同级小问起始位置一致，多行推导对齐。避免题干末尾与解答开头无故分离；长题允许在逻辑边界分页，避免整题强制同页造成大空白。修改共同源后重导出并复查受影响页面。
4. 检查实际文件能打开、链接指向本轮成品。同时交付同一版式的 PDF 与 LaTeX 时从最终目录重新编译，核对图片引用；保留原 PDF，另存重编译结果供页面比较。仅保留实际选用的开源字体与许可证；精简交付、文件复制与完整性复验按 Recto 约定执行，只清理能确认的本轮生成文件，原始材料和来源不明文件保留。

最终给出实际成品链接，简述范围、已生成的 PDF 页数、适用时的题目与小问数量，以及未解疑点。下载失效时重新检查文件并提供有效链接，不能只复述旧链接。区分指令走读、内容核对、导出成功、完整性复验、逐页视觉检查和最终目录重编译；未完成的层次如实说明，完整性报告不替代视觉 QA，未用原生 Word 打开不声称原生 Word 验收。
