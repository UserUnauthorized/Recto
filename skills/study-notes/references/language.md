# 讲解、材料与考试语言

分别识别三个信息：**主要输出语言、材料语言、已明确的考试／工作语言**。它们可能不同，也可能一致。

1. 主要输出语言先遵从本次明确要求，其次沿用会话已确定的偏好，再依据用户自己交流时主要使用的语言。不要把附件、引用内容或 skill 本身的语言当作用户偏好。确实无法判断且影响成文时才问一句。
2. 检查材料实际语言；混合语言时按概念保留对应的原文词。考试语言只有用户或材料明确说明时才采用，不能从外语 PPT 推断“考试也用外语”。
3. 标题、正文、推导解释、图注和答案以主要输出语言为主；原题引用和另行要求的考试答案保留各自语言。若材料语言不同，在关键概念首次出现时写成“主要语言术语（材料原词）”；优先保留读课件、识别题干、区分易混概念需要的名称、缩写和指令词，不逐句双语复述，也不为日常词汇逐一加注。
4. 已明确的考试语言不同于主要语言时，补充必要的考试术语或题干表达。若它又与材料语言不同，只对确有需要的词增加对应项，避免每个概念都堆三种语言。选用外语自测题时，用主要语言解释题意和答案；没有此需求时不强加外语试卷。
5. 原词优先核对课件、教材或题解，全文统一同一概念的译法和缩写。歧义影响理解时查证或说明，不能凭词形猜译。两种语言相同时，不强制增加第三种语言；用户明确不要双语标注时遵从。

例如，主要语言为西班牙语、材料为英语时可写 `campo eléctrico (electric field)`；主要语言为英语、材料为中文时可写 `electric field（电场）`。示例只说明标注关系，不设定默认语言。公式符号及其约定沿用材料，不因翻译悄悄更名。
