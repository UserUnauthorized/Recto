# 指定题目讲解

用于作业清单、指定题号或勾选截图。覆盖单位是用户指定的题目与小问，不能用讲义的“精选代表题”规则替换它们。

## 1. 确认题目集合

逐张检查原图／原页，记录章节、原题号、指定小问、来源页和公共题组要求。作业清单若在课件末页，先定位该清单再找对应题干，不能把同章所有 Practice Problems 当作作业。重叠截图去重，保留原顺序和章节分组。

有勾选或明确题号时只解指定范围；无选题标记时按用户明确给出的范围处理，不自行假定“所有可见题”。选择不清只询问相关题目。先核对指定大题数和小问数，避免解完后才发现漏项。

“完整原题”与“作答范围”分开：原题需要全文时保留全部题干与小问，但只解指定小问，注明其余未列入本次作答；不能因为引文完整就顺带新增解答。公共要求、被引用的前问结果或图中条件必须随题保留。依赖未指定前问时，只给完成指定小问所需的前提或中间结果，不扩成该前问的完整解答。

## 2. 保留原题，再组织解答

题干保持来源语言、原文与题号，不通过翻译、简写或更正替换引文；原题疑似笔误时原样保留，核实后在讲解中注明。截图中不可辨认的条件不能猜填。

写正文前，按顺序确定每题的解答分区：

1. **范围例外**：只要提示时止于提示；只要答案时省去教学讲解。明确“只用中文”“不要外语答案”等要求优先于下列默认值。
2. **答案语言**：本次明确指定的答案语言 → 会话已确定的答案／考试语言 → 原题语言。混合语言题页逐题判断；纯公式题且无语言线索时沿用讲解语言。沿用原题语言是为了提供可直接用于作答的表达，不据此断言考试语言。
3. **完整讲解**：答案语言与讲解语言不同时，每题固定为 **原题 → 讲解 → 简洁答案**，写完该题的三个分区再进入下一题，用户只说“制作讲解”也执行。两种语言相同时合并为一套解答；用户另要考试版或精简答案时才分区。

中文讲解、英文答案的分区为：

- **Original Problem**：完整英文原题、所有小问、公共要求和必要图形。
- **中文讲解**：考查什么、为什么选这个方法、使用的条件与关键计算如何得到。解释到已经学过但不会独立解题的学生能跟上；只在确有风险时指出易错点。
- **English Answer (Exam-ready)**：全英文与数学公式，逐个对应指定小问，按下面的独立作答步骤生成。

其他语言组合按同样职责使用对应语言的标题。先为全部指定小问建立所需分区，再填入解答；英文原题、英文术语和纯公式结果均不算英文答案。

**独立作答**：逐小问从已验算的讲解提取起始方程／定理条件、推出结果所需的关键中间式、结论，再用答案语言连接它们；精简时删教学铺垫，保留这条推理链。暂时遮住讲解区，只读答案区核对能否从所写步骤推出结论；有跳步就补入相应中间式。答案区须能独立用于作答，因此“详见讲解”不能替代步骤。

## 3. 逐题核验

每题先独立求解，再比对已有答案；检查全部指定小问的条件、推导和结果。证明题保留逻辑闭环，计算题保留能检查方法与代入的中间式；“简洁英文”不等于删掉这些步骤。

原图裁取或重绘均保留解题信息。特别检查几何点是否满足方程、单位方向是否一致、约束与边界是否处理，以及电路的节点、开关和极性。若结果与来源不一致，回查原图和计算，核实后注明勘误，不强行配平到已有答案。

## 4. 排版与完成条件

同级小问使用一致的段落／列表结构，(a)、(b)、(c) 起点相同，避免只在首问残留首行缩进。多行公式在等号或主要运算符处对齐；图尽量靠近题干，长题在推理边界续页，不能以整题不分页为由留下大片空白。

交给排版前，对照题目集合逐项销账：指定题目无漏解、重解或越界解答；原题、公共要求、必要图形齐全。需要分区时，每个指定小问必须同时有讲解和目标语言的简洁答案，条件与结果一致；答案须含必要推理或计算，缺任一区先补齐再导出。按请求仅给提示或答案的题目按对应范围验收。

题目数与实际小问数分别报告，不用大题数量掩盖漏问。最后执行入口的实际 PDF 逐页验收。
