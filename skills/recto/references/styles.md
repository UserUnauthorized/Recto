# 两套版式

## 清爽课程讲义 reference

视觉来自用户选定的物理练习与化学讲义组合。A4 近似尺寸 595×842pt，左右27.75pt，上下12mm；正文宋体与 Times New Roman 12pt，18pt 基线，段距9pt。标题16.5pt，副标题与节标题13.5pt。数学使用 New Computer Modern Math，比例1.21；细黑线只用于标题和主要节分隔。底部页码10pt，居中。没有封面、边栏卡片、彩色框或装饰性元件。

Word 使用 A4 标准尺寸，同等正文尺寸和边距；为了原生分式不剪切，行高为最小18pt。原生公式不保证与 Typst 数学字体逐字相同。

## 国标正文 gbt9704

范围是 GB/T 9704-2012 中正文、表格、附件和页码相关版式，按用户要求去除公文版头、署名等要素。

- A4，天头37mm，订口28mm；版心156×225mm，底35mm、右26mm。
- 正文三号16pt仿宋；标题二号22pt小标宋。一级黑体，二级楷体，三级四级仿宋。
- 序号沿用“一、”“（一）”“1.”“（1）”；标题与正文首行缩进两字。
- 普通纯正文按22行、28字标定；标题、数学、表格不是每页强行塞进22×28网格。
- 页码四号14pt宋体阿拉伯数字，两旁一字线；单页右、双页左，外侧空一字。Typst 将一字线上缘放在版心下7mm；Word 以页脚近似实现。
- 附件另页，首行标签，第三行居中标题，连续页码；源称“附录”时保留原称谓。
- 横向表格的 PDF 保持纵向 A4，单页表头朝订口、双页朝切口；Word 改用原生横向节以便编辑。

本地字体名称：`FZFangSong-Z02`、`FZXiaoBiaoSong-B05`、`FZHei-B01`、`FZKai-Z03`、`SimSun`。讲义另需 `Songti SC`、`Times New Roman`、`New Computer Modern Math`。字体不可随 skill 默认再分发。更换字体会改变字形与分页，需要复核。

版式依据：用户提供的 GB/T 9704-2012 PDF；对照条款5.2、5.3、7.3.1、7.3.3、7.3.4、7.3.7、7.5、8.1。此 skill 不生成完整机关公文，也不对 Word 导出作完整国标符合性认证。
