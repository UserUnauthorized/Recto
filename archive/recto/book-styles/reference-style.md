# 清爽课程讲义：两份参考的融合

## 依据

- 物理参考：用户提供的 `exam_3_18.pdf`，33 页。查看了词汇表、导数公式、运动学与受力推导等代表页面。
- 化学参考：用户提供的 `chap8.pdf`，7 页。查看了全文件概览及第 3 页题目、答案与解析的详细排版。

两份均按实际 PDF 渲染取样。文字层有部分英文未被正常提取，因此提取文本不用于重建内容；可提取的字体、字号和坐标用于测量，页面图片用于核对外观。

将物理资料的公式尺度、独立陈列与中英文混排方式，和化学资料的加粗小标题、答案层次及横线分节结合。保留黑白页面，不引入彩色面板、背景底纹或大幅装饰章头。

宋体与 Times 可使用本机同族字体。数学引擎从原件 KaTeX 转为 Typst；New Computer Modern Math 用于接近原来的数学字形，不能据此声称像素级一致。正式 skill 应检查字体是否存在，缺失时明确报告，不静默把宋体替换成黑体。

## 样张边界

使用原有 Taylor 近似样文观察同一内容的密度变化，不复制参考资料的正文，不重写公式或论证。新参考版自然流动为四页；因内容不同，不追求参考资料的页数和逐页断点相同。
