# 国标正文样式

依据用户提供的 `9704-2012-gbt-cd-300.pdf`，采用 GB/T 9704-2012 中适用于正文、表格和附件的条款。已读相关条文及图 1、图 9 等式样；没有把标准文件自身的印刷排版当作公文版式。

## 条款与实现

| 条款 | 要求 | 本次实现与证据 |
| --- | --- | --- |
| 5.1、5.2.1 | A4；天头 37mm；左白边 28mm；版心 156 × 225mm | 上 37、下 35、左 28、右 26mm；PDF 页面及文字边界量测 |
| 5.2.2、5.2.4 | 一般三号仿宋；黑色 | 正文 16pt 方正仿宋；全部黑色；字体嵌入核验 |
| 5.2.3 | 一般 22 行、每行 28 字，撑满版心；特定情况可调整 | 16pt 字号配合约 -0.215pt 字符间距和约 29.609pt 基线间距；实际纯正文测试页验证 22 × 28 |
| 7.3.1 | 一般二号小标宋，居中 | 22pt 方正小标宋；以版心为准居中；无红头时从版心首行开始 |
| 7.3.3 | 正文左空二字、回行顶格；四级序数与字体 | “一、”黑体，“（一）”楷体，“1.”和“（1）”仿宋，均三号；首行和各级标题空二字 |
| 7.3.4 | 附件说明正文下空一行、左空二字；名称回行对齐 | 说明与正文保持一行空白；编号和名称分列；名称后不加标点 |
| 7.3.7 | 附件另面；第一行三号黑体标签；第三行居中标题；页码连续 | `attachment` 与 `attachment-heading` 生成；第 3 页为附件 1，第 4 页为附件 2；可用 `label: "附录"` 保留源稿标签 |
| 7.5 | 四号半角宋体页码，两侧一字线；线距版心下缘 7mm；单右双左空一字 | SimSun 14pt；横线以绝对页面坐标定位；第 1–5 页逐页测量 |
| 8 | 横排表格页码位置与其他页一致；单页表头在订口、双页表头在切口 | A4 页面保持纵向，只旋转表格内容；第 4 页表头朝右、第 5 页朝左；页码保持正向 |

字距与行距是本模板为实现版面结果选择的实现参数，不把常用的 28pt 行距误写为标准唯一要求。当前 22 × 28 测试适用于纯正文，混入标题、表格等内容时按实际排布处理。

## 表格约定

纵表最大宽度为 156mm；横表最大宽度为 225mm。默认使用三号仿宋正文、三号黑体表头、0.5pt 黑色表线、横向 6pt 和纵向 7pt 单元格内边距。表格列宽、线宽和单元格留白是本样式的设计约定，不声称由该国标逐项强制规定。`grid-table` 的 `cell-size` 可显式调整特殊表格字号。

纵表使用可重复表头。横排页以 `landscape-attachment` 明确分页，续页传入 `continuation: true`；它不会自动把任意超长横表拆成若干页。更换表格内容后应检查高度和断页，不能以缩小到难以阅读的字号掩盖溢出。

## 样张内容

1. 总标题、连续正文及四级标题。
2. 纵向表格、正文与两项附件说明。
3. 附件 1：登记表与补充正文。
4. 附件 2：横排对照表，双页表头朝切口。
5. 横排表续页，单页表头朝订口。

附件编号和名称由同一份材料确定；复制模板时应同步正文说明与附件标题。源稿若明确使用“附录”，保留该词，借用附件的另页、标题位置和连续页码规则；不声称标准另有一套独立的“附录”规则。

## 范围

只实现用户指定的文字、表格与附件版式。红头、主送机关、文号、署名、成文日期、印章和版记均不生成，也不为它们保留占位区域。没有输入资料时使用原创样文，不补写真实机构、作者或签发信息。

验收表述为“按 GB/T 9704-2012 的相关版式参数生成”。实体纸张、印刷套正、油墨、装订，以及特殊机关模板不属于本次 PDF 样张验证范围。
