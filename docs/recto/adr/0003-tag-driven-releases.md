# 标签决定发行版本

2026-11-11，用户确认以后只需向 `main` 已合并提交推送递增的 `vX.Y.Z` 正式版本标签，不再手工更新版本文件或创建版本 PR。安装包按标签写入版本，完整自动检查及下载校验通过后发布；随后由 GitHub Actions 向 `main` 提交插件清单的版本更新，使现有 Marketplace 安装入口能够识别新版。

标签不移动。因此标签源码中的 `plugin.json` 可以仍记录上一版，正式 ZIP 中的清单以标签为准；从标签源码复现发行包时必须显式传入该标签版本。这个取舍保留了不可变的发布提交，同时满足不增加人工版本步骤的要求。GitHub 自动生成的源码归档是源码快照，推荐安装正式 ZIP 或同步后的 Marketplace 版本。

发布采用 Linux 完整回归、真实导出和干净消费者验证作为自动门槛。原生 Word／WPS 的人工视觉验收针对相关排版变更进行，不作为每个标签的人工批准步骤。已公开资产不覆盖，失败任务可以重跑；若发布已成功而清单同步失败，重跑核对原资产后只补同步，不回退公开版本。
