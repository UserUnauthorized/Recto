# 首版使用 Typst

2026-10-19，用户确认首版统一采用 Typst，输出 PDF 与可重新编译的源文件。主要用途是数学讲义、教材的电子阅读和自行打印，使用方式参照 Kami，由 skill 整理用户提供的正文或资料。Typst 的原生数学、字体配置与页面布局适合形成统一模板系统；先不维护第二套 LaTeX 模板，以免每套风格承担两份实现与验证成本。以后若有必须使用出版社 LaTeX 模板的具体需求，再单独评估。

默认忠实排版，不擅自改动数学内容；疑似错误应指出，由用户决定。

用户已选定「清爽课程讲义」，并要求删除其余三个探索方向；现仅保留该样式，同时新增 GB/T 9704-2012 的正文、表格、附件样式。两者均使用 Typst。新国标样式按用户要求不含红头和署名，具体条款与验证范围见 [国标原型记录](../../../archive/recto/book-styles/gbt9704-style.md)。正式 skill 位于 [`skills/recto/`](../../../skills/recto/)。

用户随后确认支持 `.typ`、`.pdf` 并提出 Word 需求。采用共同语义 Markdown，经 Pandoc 分别生成 Typst 和含原生 OMML 数学的 DOCX；PDF 仍由 Typst 编译。没有增加第二套 LaTeX 排版引擎。直接将复杂 Typst 转为 Word 的路径在计数器与交叉引用上出现信息丢失，因此不作为默认导出。Word 保留可编辑正文、表格与公式，不承诺与 PDF 逐页一致；国标横向表格在 Word 中使用横向节。

用户明确区分生成与转换：生成或改写内容时加入按需图解、来源核查与去 AI 腔步骤，借鉴 Kami 的工作方式；纯 Markdown 转 PDF／Word 跳过这些编辑步骤，最多附简短建议。局部改写授权只作用于指定部分。
