# Recto

面向数学讲义、教材与正式文字材料的排版 skill，服务于电子阅读和自行打印。当前模板包括清爽课程讲义与国标正文两种用途。

## Language

**排版稿**：根据用户提供的内容整理出的可阅读、可打印文稿。默认保持原文、公式和论证，只整理层级与版式，保留原编号。

**书籍风格**：字体搭配、版心、标题层次、页眉页码和数学环境共同构成的视觉体系；同一风格可用于中文、英文和混排内容。

**混排**：中文、英文、数字与数学表达式出现在同一文稿或段落中的排版情形。

**样张**：用于比较书籍风格的实际阅读页，包含连续正文、公式和数学环境。
_Avoid_：仅展示封面而没有正文的效果图。

**国标正文样式**：采用 GB/T 9704-2012 中页面、正文、表格、附件与页码的相关版式参数。本项目按用户要求不包含红头、署名及其他发文要素，不等同于完整正式公文。

**附件／附录**：随正文编排的补充材料。国标使用“附件”一词；源稿明确写“附录”时保留原标签，使用另页起排与连续页码的布局规则。

**共同源**：三种导出使用的同一份语义 Markdown，公式用 LaTeX 数学记法。生成的 `.typ` 是可独立修改和重新编译的排版源，但内容更新优先回到共同源以避免 Word 与 PDF 分叉。

**转换模式／生成模式**：转换只忠实转换与排版；生成模式仅在用户授权成文、补写或改写时启用结构梳理、配图和去 AI 腔检查。原文质量本身不构成改写授权。
