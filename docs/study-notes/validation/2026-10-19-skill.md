同步 README 用途表、使用与单独安装说明、插件展示文案。插件打包由只收录 `recto` 改为检查并收录 `skills/*/SKILL.md` 对应的 skill；未修改排版脚本或模板，未发布版本或更新本机安装。

## 行为走读

人工对照 `checks/study-notes/scenarios.md` 的 A–L 场景与最终入口；这是指令走读，不是完整文档生成测试。

| 场景 | 核对结果 |
|---|---|
| A：参考会话 | 保留简洁讲解、原词、例题取舍、图片及默认交付，不固定样张数量 |
| B–D：不同主要语言与源语言 | 明确指令优先于会话偏好，引用／附件语言不冒充用户语言，标注方向随语言关系改变 |
| E–F：同语种、关闭标注、三语与混合材料 | 不强加英语，不逐句双语，不机械堆叠三语；遵从明确例外 |
| G：简洁与覆盖 | 合并重复而非删不同知识点，保留条件、关键步骤及用户要求保留的题目 |
| H：转换与局部改写 | 原样转换不触发教学写作，局部授权不扩大 |
| I：识别错误与来源错误 | 回看原页、独立复核，未解决的歧义不编造 |
| J：材料／依赖缺失 | 请求真正必需的输入，允许完成不受影响稿件，不声称已有 PDF |
| K：语言排版 | 检查模板语言、字形和方向，不以编译成功声称全语种支持 |
| L：交接与重编译 | 完成稿走 Recto 转换模式，交付资源完整且要求解包重编译 |

另以 `zhipu/glm-5.3`、`reasoning_effort=max` 执行一次独立子代理试走。输入仅为 skill 和三个请求，不提供场景预期：西班牙语讲英文电场材料、英语讲中文运动学术语、中文用户要求德语 PPT 原样转 PDF；另检查缺少 Recto 的情况。

实际输出正确选择了西班牙语主体加英语关键词、英语主体加中文关键词、原样转换不写新讲解，以及缺依赖时不虚报 PDF。子代理提出的译词选择需要依据原材料统一，与入口规则一致。

该试走不构成学科内容验收：其运动学首段把“路程除以经过时间”笼统写成速率，而该表述应区分平均与瞬时量；电场段也只给了简写公式。未把这些段落纳入 skill 或当作已核准样稿，实际讲解仍须执行入口的条件、符号和计算核对。
