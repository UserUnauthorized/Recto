# 2026-11-18 自学讲义从哪里讲起

《完成二阶电路讲义》里，用户只说“做第八章的自学讲义”，读完第一版后追问为什么一上来就列方程。通过 `read_thread` 核对了两轮消息。可见材料只有对话，以下试写使用自拟题设。

## 同一道电路题

从 Recto 入口试写一节讲义。材料把特征方程放在前面，把具体电路放在后面。电容原有 6 V，合上开关后经电阻和线圈放电。电阻为 3 Ω，电感为 1 H，电容为 0.5 F，初始电流为零。各轮均以独立上下文运行 `zhipu/glm-5.3`，推理设置为 `max`。写作时提供题设和指定版本的技能，校订时另给实际初稿。

| 试写 | 从正文读到的结果 |
|---|---|
| 原规则（`2905abf`） | 解释了电流方向就开始用导数。从电路方程跳到“其特征方程为”，读者无法重做这一步。 |
| 第一轮修改 | 开头问电流会不会突然变大，却立即用“电流变化率就会无限大”解释。读者仍要预先会导数。 |
| 加入具体操作示例 | 确认试写者读到了新参考全文，返回的正文仍直接用导数记号和 KVL，没交代二次方程的来历。 |
| 写成 Markdown 初稿 | 这次能从指数函数试代推出特征方程，但电流变化率还是先列式、后解释，且误把电容倒数的单位写成每平方秒。随后用同一份实际稿检验交付前校订。 |
| 独立校订这份初稿 | 校订者改正了系数的量纲，但仍在解释导数前使用它。工作记录称“可跟做”，稿中找不到对应的示范。由此把首次学习的开头改成单独写入并读回同一份稿的步骤。 |
| 最终规则的独立整节写作 | 试写者自行撤回了它创建的文件，没有留下可复核的成稿。这轮不计作通过。 |
| 本地按最终流程实作 | 先把开关前后的故事写进正文，读回后才往同一份稿里续写。首次使用导数前有两次读数的除法，二阶导数前有增长速度从 6 降到 5 的例子。试代指数函数并消去公共因子之后才命名特征方程。所得电流回到开头的判断核对。 |

用 Python 标准库核对了方程的两个根 −1、−2，以及由初值确定的两个系数 6、−6。所得电流从 0 A 起步，初始变化率为 6 A/s，在约 0.693 s 时达到 1.5 A。这项检查只验证计算。

本地实作的样稿保存在忽略目录 `output/study-notes/rlc-final/content.md`，逐项摘句在同级的 `rlc-final-qa/coverage.md`。另一个上下文只读样稿，从首段指出了两次电流为零的原因，也能找到算导数和得到特征方程的出处。它指出从一个指数函数的数值例子跳到任意指数的求导公式仍缺依据。于是补入两步，先解释换起点时增加量怎样缩放，再解释时间走一步时指数走多远。

## 其他入口与范围

英文作业试写中，中文用户只要求讲解 (a)。实际正文从句子里的动作 *chased* 问“追谁？”，找到 *the cat* 才引出直接宾语。英文答案独立回答 (a)，(b) 仅随题引用。另走读了“标题叫复习但从未学过”、已学过只要公式、只给提示，以及原样转 PDF 四个分支。

另一份课件先列条件概率公式，再给出十个水果的数据。试写稿先带读者在四个熟水果里找出两个苹果，得到二分之一，再把“只看熟水果”写成条件概率。回读记录摘出了正文里缩小范围的原句。数学复核时把“分母为零”的说明限定在题设的有限个水果内。
