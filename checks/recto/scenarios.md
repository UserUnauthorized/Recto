# Recto 人工行为检查

这些场景用于对照 `skills/recto/SKILL.md` 和 `references/authoring.md` 走读预期行为，不是自动化测试，也不证明真实渲染结果。

## A. 忠实转换

请求：「把这份 Markdown 排成 PDF，只要 PDF，不要改内容。」

- 进入转换模式，默认 `reference`。
- 最终只交付 PDF；检查 PDF 依赖 LuaLaTeX 与 `latexmk`，逐页完成 PDF 视觉 QA，不为 QA 把 Markdown、LaTeX 或 DOCX 加入交付目录。旧 `typ` 请求停止并提示改用 `tex`。
- 不补标题、例子、图、引用或研究；无源标题时成品没有新增可见标题。
- 只做语法适配、层级整理和逐页 PDF QA；疑似错误只提示。

请求：「把这份 Markdown 导出成 LaTeX，只要 TeX 源，不要 PDF。」

- 进入转换模式，按 `--formats tex` 检查 Pandoc、Python 和字体依赖，不要求、不检查、不安装 `latexmk` 或 TeX 引擎。
- 交付整理后的 TeX 源及必要图片、字体与许可证；检查公式映射、图片引用和导出日志。
- 本机没有 TeX 引擎时说明 TeX 为未编译源；不为了生成临时 PDF 而安装 TeX，也不把“源码生成成功”说成渲染通过。

## B. 全文生成

请求：「根据这三份资料写一份数学复习讲义，并导出 PDF 和 Word。」

- 进入生成模式，默认 `reference`。
- 读取 authoring 流程；先核对原始材料、公式和事实，再组织正文。
- 只在图比文字更能说明关系时配图，并保存图源；对新增内容做去 AI 腔检查。
- 输出 Markdown、LaTeX、PDF，并增加 `.docx`；PDF 逐页视觉 QA，DOCX 公式为 OMML 并做渲染 QA。
- PDF 与 `latex/` 同时交付，从最终目录用 `latexmk` 重新编译并比较页面，确认图片与字体路径可迁移。

## C. 局部授权

请求：「全文保持原样，只把第 3 节改得更好懂，并给它的算法加流程图。」

- 第 3 节进入局部生成模式；其余章节按转换模式保留。
- 图只加给第 3 节算法；不改其他正文，不给全篇补总结图。
- 去 AI 腔检查只作用于第 3 节；原文其他部分的生硬表达不改。
- 修改后从共同源重导出所有受影响格式。
- 同类请求「补一个例子」只授权新增该例；未点名章节不构成全文改写授权。

## D. 国标正文转换

请求：「按这个国标样式把说明导出 Word，只要文字表格附录和 Word 成品，不要 PDF、TeX、红头和署名。」

- 进入转换模式，选择 `gbt9704`。
- 最终只交付 `.docx`；按 `--formats docx` 检查依赖，不要求、不检查、不安装 `latexmk` 或 TeX 引擎。
- 保留文字、表格和附录；不加红头、发文字号、主送机关、署名、日期、印章或版记。
- 确认公式为 OMML，用既有 DOCX 渲染路径逐页检查；不称为完整国标公文认证，也不因 PDF 链路缺 TeX 而阻塞。

## E. 首次使用、缺项和离线导出

- 插件 onboarding 或「检查并安装 Recto」：只检查环境并补缺，不索要正文，不自造样例交付。
- 新电脑缺少 Pandoc 或 Python 包：检查报告列明缺项，进入 setup 安装分支，复查通过后继续原转换；不能到“缺依赖”就结束。
- 依赖齐全：不联网、不重复安装，不改系统 Python。
- 缺少原字体：使用随包字体，提前简短说明，并在报告保留映射；PDF 和 Word 使用同一选择。用户明确要求原字体时指出缺项并等待原字体，不自行替换。
- 用户只给 Markdown 要 PDF：即使经历安装流程，仍是转换模式，不扩写、配图或去 AI 腔。
- Word-only 或 TeX-only 请求缺 `latexmk`/TeX：不安装、不判为缺依赖；Word-only 继续 DOCX 渲染验收，TeX-only 按未编译源说明边界。
- Word 渲染器不可用：标明视觉验收待办，不能把 OMML 数量或导出成功说成渲染通过。

## F. 精简交付与已有目录清理

- 未指定格式：交付一个 Markdown、PDF、`media/`、`latex/`，LaTeX 子目录只留源文件和必要字体、许可证。没有图片时不创建空图片目录。
- Markdown 和 LaTeX 共用 `media/`，没有“素材”等中文目录或第二份图片；从最终位置重新编译可读到图片。
- 默认不生成 ZIP、REBUILD、export-report、QA 和预览文件；用户明确要求 ZIP 时才额外打包。
- 清理已知旧导出前核对源稿、引用和重编译结果；已有 PDF 保持原字节，重复图确认哈希一致后才去重。
- 只清理用户点名或能确认本轮生成的文件；未知文件和原始材料不因“精简”被自动删除。
